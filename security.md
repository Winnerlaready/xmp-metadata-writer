## ❓ What Is XMP

| **Term** | **Description** |
|-----------|-----------------|
| **XMP** | Adobe metadata standard |
| **Schema** | Namespace of tags |
| **ExifTool** | Metadata CLI |
| **Sidecar** | External `.xmp` file |
| **Namespace** | `dc:`, `xmp:`, `photoshop:` |
| **Embed** | Written inside file |

**Why use it?**
- ✅ Copyright tracking
- ✅ Searchable archives
- ✅ Batch updates
- ✅ Cross-format
- ✅ Free guide
